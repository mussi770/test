# 🐍 משחק הנחש - Snake Game

אפליקציה קטנה ומגניבה - משחק הנחש הקלאסי בטרמינל!

## 🎮 תיאור המשחק

משחק Snake צבעוני ואינטראקטיבי שרץ בטרמינל. שלוט בנחש, אכול תפוחים אדומים, גדל והשג ניקוד גבוה!

### תכונות:
- 🌈 גרפיקה צבעונית בטרמינל
- 🎯 מערכת ניקוד
- ⚡ מהירות גוברת עם הניקוד
- 🎨 עיצוב מסודר עם מסגרות
- 🕹️ בקרה נוחה עם מקשי החיצים

## 📋 דרישות

- Python 3.x
- מודול `curses` (מותקן כברירת מחדל ב-Linux/Mac)

## 🚀 הפעלת המשחק

```bash
python3 snake_game.py
```

## 🎯 איך לשחק

- **חיצים** - הזז את הנחש (למעלה, למטה, שמאלה, ימינה)
- **Q** - יציאה מהמשחק
- **מטרה** - אכול את התפוחים האדומים (◆) כדי לגדול ולהשיג ניקוד
- **אזהרה** - אל תתנגש בקירות או בעצמך!

## 📊 מערכת הניקוד

- כל תפוח = 10 נקודות
- ככל שתשיג יותר נקודות, המשחק יהיה מהיר יותר!

## 🎨 אגדה

- `●` - ראש הנחש (ירוק)
- `○` - גוף הנחש (ירוק)
- `◆` - תפוח (אדום)
- `═║╔╗╚╝` - מסגרת (ציאן)

## 💡 טיפים

1. תכנן את המהלכים שלך מראש
2. השתמש בקירות לטובתך
3. אל תלחץ יותר מדי כשהנחש מתחיל להאריך
